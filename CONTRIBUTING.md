# Contributing

The project uses the MIT License. Submit only contributions you have authority to license, and preserve applicable third-party notices. Report documentation or static-validation issues with minimal non-sensitive examples. Never attach MRI, patient identifiers, private paths, checkpoints or credentials.

Keep src.* imports and frozen scientific files intact. Separate release/documentation changes from proposed experimental changes; explain scientific consequences and obtain author review for the latter. Run only `python scripts/validate_release.py` for release checks. Do not run notebooks or the historical smoke helper as routine tests. Maintainer review and response times are not guaranteed.
