# Retained notebook workflows

The 17 canonical notebooks are retained unchanged; no cells were executed. Read in numeric order, with 15.1 following 15. All workflows need private prerequisites beyond the public aggregates; reading requires no GPU. The table distinguishes historical GPU use from static reading.

01-03 document shared dataset, patient-disjoint splitting and preprocessing. 11-13 define the A0-A5 controlled ablation route including principal A4; 08-10 cover baselines; 14 covers saved-prediction statistics; 15-16 cover A4 interpretation and consolidated results.

**04-07 remain explicitly original A5, not A4.** They are retained as the minimum canonical A5 comparator/prerequisite chain: 04 writes architecture records, 05 writes the fingerprint/complexity records used by main training and baseline/ablation setup, 06 trains the A5 checkpoints later reused, and 07 documents their evaluation. Notebook 06 directly invokes `scripts/phase6_smoke.py`; that experimental helper remains solely to avoid breaking this route and is never part of static validation. Private fingerprints and checkpoints are still required; retained source does not make a frozen rerun immediately executable.
