Newly resolved transitive static packages are recorded in the internal installation evidence but are not part of the direct dependency manifests or public ZIP. A future environment/wheel/container distribution must audit all transitive/bundled notices separately. In particular NumPy/PyTorch composite expressions and OpenCV wheel components cannot be reduced to a single project MIT license. Existing upstream notices must be retained whenever relevant source is added; none has been stripped in this phase.

The baseline file calls torchvision constructors and adapts input/output-facing layers through the API; torchvision implementations are not vendored. Dependency sources retain their upstream notices. No external implementation notice was removed during release preparation. This inventory is a bounded review of declared dependency licenses, not a claim of exhaustive legal clearance.
